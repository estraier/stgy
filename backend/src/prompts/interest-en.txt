==== Task Description ====

As a scriptwriter, you will now depict a scene in which the protagonist reviews the history of posts viewed on a social networking service.
Based on the protagonist's personality and the series of posts, describe what the protagonist would be interested in.
Use the vocabulary and sentences in the protagonist's personality description only as reference; do not repeat them verbatim. Make the protagonist's values, points of attention, and quirks apparent in the interests.
Preserve the coherence of the protagonist's personality, and develop the protagonist's previous interests gradually when composing the current interests.
Treat the viewed posts and user profiles as material to be interpreted through the protagonist's personality, values, and existing interests, and determine what the protagonist personally becomes interested in as a result.
Extend the interests toward related fields, questions, contrasting perspectives, concrete applications, and other directions that naturally follow from the protagonist's personality.
When multiple posts concern the same topic, use that shared topic as a starting point for protagonist-specific adjacent issues and surrounding fields, and actively incorporate them into the current interests.
Write the output in JSON format.
- Put the new description of the protagonist's interests in the "interest" field.
- Put suitable tags representing those interests in the "tags" field.
  - Use at least one tag from the Nippon Decimal Classification (NDC).
    - Keep the Japanese NDC classification code and write an English translation of its label after a colon. Do not substitute a Dewey Decimal Classification (DDC) code.
      - Examples: 000:General works, 100:Philosophy, 200:History, 300:Social sciences, 400:Natural sciences, 500:Technology, 500:Engineering, 600:Industry, 700:The arts, 700:Fine arts, 800:Language, 900:Literature
      - Some NDC labels contain multiple terms, such as "Technology. Engineering". In that case, choose the more suitable term.
        - Examples: 500:Engineering, 700:Fine arts
    - If a more suitable narrower NDC category exists, use it. Make a reasonable effort to use a lower-level category.
      - Examples: 140:Psychology, 007:Information science, 240:History of Africa, 326:Criminal law
      - Use a top-level NDC class (000/100/200/300/400/500/600/700/900) only when no more specific lower-level class can be identified.
    - If a more suitable decimal subdivision exists, use it and write only its final label after the colon.
      - Example: 007.63:Software
    - Existing input tags may lack classification codes; still include the NDC code in output NDC tags.
  - For the remaining tags, freely write suitable search terms.
    - Examples: Balrog, Futako-Tamagawa, hamburger, information theory, cybernetics
- Output only the JSON data; omit formatting, acknowledgements, and explanatory text.
  - Follow the JSON specification strictly, pay attention to commas and escaping, and ensure that validation will pass reliably.
