==== Task Description ====

As a scriptwriter, you will now depict a scene in which the protagonist reads a single post on a social networking service together with the reply context leading to that post.
Only the final post shown is the target of evaluation. Use the reply context solely as reference for understanding the meaning and intent of that post.
Describe the impression that the protagonist would have of the target post, based on the protagonist's personality.
Use the vocabulary and sentences in the protagonist's personality description only as reference; do not repeat them verbatim. Make the protagonist's values, points of attention, and quirks apparent in the impression.
If the protagonist cannot understand the context of the post, has no interest in it, or has no particular reaction to it, do not force meaning or interpretation onto it. In that case, record that state briefly in the "impression" field, for example by saying that the protagonist does not really understand it, has no particular impression, or is not interested.
Write the output in JSON format.
- Put the protagonist's impression of the target post in the "impression" field.
  - Do not merely summarize the post. Explain what the protagonist feels or thinks about its content in light of the protagonist's personality.
  - Do not write an impression of the reply context itself. Use it to understand the target post, and write the impression of the target post.
- Put suitable tags representing the target post in the "tags" field.
  - Use at least one tag from the Nippon Decimal Classification (NDC).
    - Keep the Japanese NDC classification code and write an English translation of its label after a colon. Do not substitute a Dewey Decimal Classification (DDC) code.
      - Examples: 000:General works, 100:Philosophy, 200:History, 300:Social sciences, 400:Natural sciences, 500:Technology, 500:Engineering, 600:Industry, 700:The arts, 700:Fine arts, 800:Language, 900:Literature
      - Some NDC labels contain multiple terms, such as "Technology. Engineering". In that case, choose the more suitable term.
        - Examples: 500:Engineering, 700:Fine arts
    - If a more suitable narrower NDC category exists, use it. Make a reasonable effort to use a lower-level category.
      - Examples: 140:Psychology, 007:Information science, 240:History of Africa, 326:Criminal law
      - Use a top-level NDC class (000/100/200/300/400/500/600/700/900) only when no more specific lower-level class can be identified.
    - If a more suitable decimal subdivision exists, use it and write only its final label after the colon.
      - Example: 007.63:Software
    - Existing input tags may lack classification codes; still include the NDC code in output NDC tags.
  - For the remaining tags, freely write suitable search terms.
    - Examples: Chun-Li, Setagaya, sandwich bread, information theory, cybernetics
- In the "shouldLike" field, answer true or false to indicate whether the protagonist should like the target post.
  - Set it to true only when, in light of the protagonist's personality and interests, the protagonist genuinely thinks the post is good and wants to express that reaction.
- In the "shouldReply" field, answer true or false to indicate whether the protagonist should reply to the target post.
  - Set it to true only when, based on the protagonist's personality and interests, the protagonist can make a genuinely useful reply.
- Output only the JSON data; omit formatting, acknowledgements, and explanatory text.
  - Follow the JSON specification strictly, pay attention to commas and escaping, and ensure that validation will pass reliably.
